# 2. Poin-Poin Penting & Pengetahuan Baru
*Mengetahui 8 Bentuk Kegiatan Pembelajaran MBKM sebagai berikut :
1. Pertukaran Pelajar (belajar di prodi/kampus lain).
2. Magang / Praktik Kerja (pengalaman langsung di industri).
3. Asistensi Mengajar (membantu pembelajaran di satuan pendidikan).
4. Penelitian / Riset (meneliti bersama dosen atau lembaga riset).
5. Proyek Kemanusiaan (terlibat dalam program sosial kemanusiaan).
6. Kegiatan Wirausaha (merintis dan mengembangkan usaha mandiri).
7. Proyek Independen (menggarap proyek inovasi secara mandiri).
8. Membangun Desa / KKN (pengabdian masyarakat di desa).
* Mengetahui program Unggulan MSIB (Magang & Studi Independen Bersertifikat) sebagai nerikut :
1. Belajar sambil bekerja di perusahaan/organisasi mitra, mengerjakan proyek nyata di bawah bimbingan mentor industri.
2. Keduanya berdurasi 1 semester, dikonversi menjadi 20 SKS, memperoleh sertifikat resmi, serta membuka peluang rekomendasi penempatan kerja di mitra.
* Metode Pembelajaran (PjBL, PBL, & CBL)
1.PJBL: Belajar lewat karya nyata (produk, prototipe, atau aplikasi) yang dikerjakan secara tim.
2.PBL : Belajar lewat pemecahan masalah nyata yang kompleks di mana dosen berperan sebagai fasilitator.
3.CBL : Analisis kasus nyata dari industri/masyarakat melalui tahapan membaca kasus, identifikasi masalah, diskusi tim, perumusan solusi, hingga presentasi & refleksi.
*  Manfaat bagi Mahasiswa Politeknik
1. Memperkuat keterkaitan antara pendidikan keterampilan terapan kampus dengan kebutuhan dunia kerja nyata.
2. Memperoleh kompetensi relevan, portofolio profesional, serta terhubung langsung dengan mentor serta praktisi industrI.
* Tips Mengikuti MBKM/MSIB
1. Pastikan data diri dan administrasi akademik sudah sesuai.
2. Daftar melalui portal resmi Kampus Merdeka.
3. Diskusikan rencana program dan konversi SKS dengan koordinator MBKM atau Dosen Pembimbing Akademik (DPA).
4.  Susun CV, portofolio, serta pastikan kedisiplinan dalam mencatat laporan harian kegiatan.
 Memberikan peran dan batasan yang spesifik pada AI menghasilkan kode aplikasi (seperti pembuatan *Student Task Planner* berbasis web dengan HTML, CSS, dan vanilla JS) yang jauh lebih akurat dan minim error.
 Riwayat kode tercatat secara transparan, memudahkan pelacakan bug, serta mempermudah pengerjaan proyek kelompok tanpa harus saling mengirim file ZIP manual.
